## What are custom values in GoHighLevel?

<p className="answer">Custom values are account-level variables in a GoHighLevel sub-account, such as the business name, phone number, address or booking link. They are inserted into emails, SMS, pages and workflows with merge fields, so changing the value once updates every place it appears. Custom fields, by contrast, store data per contact.</p>

## How is it used?

- Building snapshots that adapt to each client's details.
- Keeping one booking link or phone number correct across every email and page.
- Changing an offer or price in one place before a campaign.

## What usually goes wrong?

- Values typed directly into emails and pages instead, so updates are missed.
- Custom values confused with custom fields, so contact data ends up in the wrong place.
- Merge fields with typos that print as raw text in emails.
