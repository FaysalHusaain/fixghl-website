## What is a snapshot in GoHighLevel?

<p className="answer">A snapshot is a saved copy of a sub-account's build that can be loaded into other sub-accounts. HighLevel's help center lists what it carries, including workflows, funnels, calendars, forms, emails, custom fields and custom values. It does not carry contacts, conversations, appointments or integrations.</p>

## How is it used?

- Agencies build one template sub-account and load it into every new client.
- SaaS mode plans can load a snapshot automatically when a client signs up.
- Snapshots can be updated and pushed to sub-accounts that already use them.

## What usually goes wrong?

- Text and links hard-coded into emails and pages instead of using custom values, so every client account needs manual edits.
- Integrations expected to come across, when they have to be reconnected in each sub-account.
- Pushing a snapshot update that overwrites changes a client made.
